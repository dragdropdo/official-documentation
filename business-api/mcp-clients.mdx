# DragDropDo MCP server

The **DragDropDo MCP server** exposes the same capabilities as the [Business API](/business-api/overview)—upload, convert, compress, merge, zip, PDF password tools, and status polling—as [MCP tools](https://modelcontextprotocol.io/). Clients connect over **Streamable HTTP** (HTTPS) at:

```text
https://mcp.dragdropdo.com/mcp
```

There are two ways to connect:

| | Sign in (recommended for assistants) | API key |
|---|---|---|
| For | Claude, Claude Code, Cursor and other assistants that support MCP sign-in | Scripts, CI, custom applications, any client that can send headers |
| Setup | Add the URL, click **Connect**, sign in to DragDropDo, **Allow** | Generate a key and send it as `Authorization: Bearer` |
| Manage | **Account → API**, listed as *Connected app* | **Account → API** |

Both give the same tools and the same [limits](#limits).

## Connect by signing in

When you add DragDropDo to an assistant, it opens a browser window: sign in to DragDropDo (Google, Microsoft or Facebook), check the request, and click **Allow**. The assistant then gets its own access, renewed automatically; you never copy a key.

The approval page shows the app's name and the address it will send you back to (for example `claude.ai`). Only click **Allow** if that is the app you are connecting.

### Claude (claude.ai, Claude Desktop, Claude mobile)

On Claude plans that support custom connectors:

1. In Claude, open **Settings → Connectors** and choose **Add custom connector**.
2. Name it (for example `DragDropDo`) and enter the URL `https://mcp.dragdropdo.com/mcp`. Click **Add**.
3. Click **Connect**, sign in to DragDropDo, and click **Allow**.

A connector added on claude.ai is also available in Claude Desktop and the Claude mobile apps. In a chat, enable it from the tools menu and ask, for example, *"Can DragDropDo convert WEBP to PNG?"*

<Note>
Uploading a file from your computer requires an assistant that can run commands, such as Claude Code or Cursor. In claude.ai, Claude Desktop and Claude mobile the tools can check what DragDropDo supports, but can't yet send a file from your device.
</Note>

### Claude Code

[Claude Code](https://code.claude.com/docs) supports remote MCP servers over HTTP. Add the server without a key:

```bash
claude mcp add --transport http d3 https://mcp.dragdropdo.com/mcp
```

Then, in Claude Code, run `/mcp`, select **d3** and choose **Authenticate**. Your browser opens: sign in to DragDropDo and click **Allow**.

Useful commands: `claude mcp list`, `claude mcp get d3`, `claude mcp remove d3`. Add `--scope project` to store the entry in the project's `.mcp.json`, or `--scope user` for your user config. See [Connect Claude Code to tools via MCP](https://code.claude.com/docs/en/mcp).

### Cursor

Add an entry with only the URL to your MCP config (user: `~/.cursor/mcp.json`, or project: `.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "d3": {
      "url": "https://mcp.dragdropdo.com/mcp"
    }
  }
}
```

In Cursor's MCP settings the server then shows a sign-in button. Click it, sign in to DragDropDo and click **Allow**.

### Other assistants

The server follows the [MCP authorization specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization) (OAuth 2.1 with PKCE, dynamic client registration). Clients find it from the `401` response and `https://mcp.dragdropdo.com/.well-known/oauth-protected-resource/mcp`.

For your security, sign-in is open to apps whose sign-in returns to one of these addresses:

- `https://claude.ai/…` and `https://claude.com/…` (Claude)
- `http://localhost`, `http://127.0.0.1` or `http://[::1]` on any port (assistants running on your computer, such as Claude Code)
- `cursor://…` (Cursor)

If your assistant isn't accepted ("Can't connect this app"), [contact us](https://dragdropdo.com/contact-us) to have it added, or use an [API key](#connect-with-an-api-key) instead.

### Managing connected apps

Every app you connect appears in **Account → API** as a *Connected app*. Connecting the same app again reuses that entry.

To disconnect an app, delete its entry there. It loses access immediately; its next request is refused and it asks you to connect again.

Connected apps don't count toward the number of API keys your plan allows.

## Connect with an API key

Use an API key for scripts, CI, custom applications, or any client that can send headers.

- Generate a **D3 API key** in the dashboard ([sign in](https://dragdropdo.com/auth/signin) → Account → API). It is the same key as for `Authorization: Bearer` on `/api/v1`.
- Send it on every MCP request in the **`Authorization`** header:

```http
Authorization: Bearer <YOUR_D3_API_KEY>
```

The server validates this key the same way as REST requests (see [Authentication](/business-api/authentication)).

### Claude Code

Add the server and pass your API key on the `Authorization` header:

```bash
claude mcp add --transport http d3 https://mcp.dragdropdo.com/mcp \
  --header "Authorization: Bearer YOUR_D3_API_KEY"
```

Claude Code merges MCP entries from `~/.claude.json` and, for project scope, `.mcp.json`. An HTTP server entry with a key looks like this (structure may vary slightly by Claude Code version—use `claude mcp get <name>` after adding to see the exact shape):

```json
{
  "mcpServers": {
    "d3": {
      "type": "http",
      "url": "https://mcp.dragdropdo.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_D3_API_KEY"
      }
    }
  }
}
```

You can use environment substitution in values where your tooling supports it (for example `Bearer ${D3_API_KEY}`), so secrets are not committed to git.

### Cursor

Add an entry with `url` and `headers`:

```json
{
  "mcpServers": {
    "d3": {
      "url": "https://mcp.dragdropdo.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_D3_API_KEY"
      }
    }
  }
}
```

Restart Cursor or reload MCP servers so the new server is picked up.

### Custom MCP clients

Use an official [Model Context Protocol](https://modelcontextprotocol.io/) client with **Streamable HTTP** to `https://mcp.dragdropdo.com/mcp`, authenticated with `Authorization: Bearer` and your API key.

The examples below initialize the session and **list tools**. Match imports and APIs to your SDK version.

<CodeGroup>

```ts NODE
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const url = new URL("https://mcp.dragdropdo.com/mcp");
const transport = new StreamableHTTPClientTransport(url, {
  // A fixed API key goes in the request headers. (authProvider is for the full OAuth sign-in flow.)
  requestInit: {
    headers: { Authorization: `Bearer ${process.env.D3_API_KEY}` },
  },
});

const client = new Client({ name: "my-app", version: "1.0.0" });
await client.connect(transport);
await client.listTools();
// await client.callTool({ name: "supported_operation", arguments: { ext: "pdf" } });
```

```python PYTHON
import os
import httpx
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client

URL = "https://mcp.dragdropdo.com/mcp"
api_key = os.environ["D3_API_KEY"]
headers = {"Authorization": f"Bearer {api_key}"}

async def main():
    async with httpx.AsyncClient(headers=headers) as http_client:
        async with streamable_http_client(URL, http_client=http_client) as (read, write):
            async with ClientSession(read, write) as session:
                await session.initialize()
                await session.list_tools()
                # await session.call_tool("supported_operation", {"ext": "pdf"})

# asyncio.run(main())
```

```php PHP
<?php

declare(strict_types=1);

use Mcp\Client;
use Mcp\Client\Transport\HttpTransport;

$apiKey = getenv('D3_API_KEY') ?: '';

$client = Client::builder()
    ->setClientInfo('My App', '1.0.0')
    ->build();

$transport = new HttpTransport(
    endpoint: 'https://mcp.dragdropdo.com/mcp',
    headers: ['Authorization' => 'Bearer ' . $apiKey],
);

$client->connect($transport);
$client->listTools();
// $client->callTool(name: 'supported_operation', arguments: ['ext' => 'pdf']);
$client->disconnect();
```

```go GO
package main

import (
	"context"
	"os"

	"github.com/mark3labs/mcp-go/client"
	"github.com/mark3labs/mcp-go/client/transport"
	"github.com/mark3labs/mcp-go/mcp"
)

func main() {
	ctx := context.Background()
	key := os.Getenv("D3_API_KEY")

	httpTransport, err := transport.NewStreamableHTTP(
		"https://mcp.dragdropdo.com/mcp",
		transport.WithHTTPHeaders(map[string]string{
			"Authorization": "Bearer " + key,
		}),
	)
	if err != nil {
		panic(err)
	}

	c := client.NewClient(httpTransport)
	defer c.Close()

	if err := c.Initialize(ctx); err != nil {
		panic(err)
	}
	if _, err := c.ListTools(ctx, mcp.ListToolsRequest{}); err != nil {
		panic(err)
	}
	// c.CallTool(ctx, mcp.CallToolRequest{ ... })
}
```

```java JAVA
import io.modelcontextprotocol.sdk.client.McpClient;
import io.modelcontextprotocol.sdk.client.McpSyncClient;
import io.modelcontextprotocol.sdk.client.transport.HttpClientStreamableHttpTransport;
import io.modelcontextprotocol.sdk.spec.McpTransport;

// io.modelcontextprotocol.sdk:mcp — use your BOM or version from https://java.sdk.modelcontextprotocol.io/

String apiKey = System.getenv("D3_API_KEY");
McpTransport transport = HttpClientStreamableHttpTransport.builder("https://mcp.dragdropdo.com")
    .endpoint("/mcp")
    .requestCustomizer(req -> req.header("Authorization", "Bearer " + apiKey))
    .build();

McpSyncClient client = McpClient.sync(transport).build();
client.initialize();
client.listTools();
// client.callTool(new CallToolRequest("supported_operation", Map.of("ext", "pdf")));
client.closeGracefully();
```

## Limits

Connected apps and API keys share your account's limits. Free accounts have a daily limit on operations; with an active subscription there is none. When the limit is reached, tools return an error such as `daily operation limit reached, resets at 2026-11-07T00:00:00Z` (midnight UTC), and the REST API answers `402 Payment Required`.

## Available tools

The tools are `initiate_upload`, `complete_upload`, `supported_operation`, `convert_file`, `batch_convert_files`, `compress_file`, `batch_compress_files`, `merge_files`, `zip_files`, `lock_pdf`, `unlock_pdf`, `reset_pdf_password`, `get_status`, `poll_status`, `batch_poll_status` and `get_download_link`. The server also sends **instructions** describing the upload and operation workflow. Use **`list_tools`** from your client after connecting to see the canonical list and schemas for your session.

## Troubleshooting

| You see | What to do |
|---|---|
| *This sign-in link has expired* | Sign-in links last 10 minutes and work only in the browser where you started. Start again from your assistant. |
| *Can't connect this app* | The assistant isn't among the apps that can sign in (see [Other assistants](#other-assistants)). Use an API key, or contact us. |
| The assistant asks you to connect again | The connection was removed under **Account → API**, or not used for 30 days. Connect again. |
| `daily operation limit reached, resets at …` | Your free daily operations are used up. They reset at midnight UTC, or subscribe for no limit. |
| `401 Unauthorized` with an API key | The key is wrong, expired or deleted. Generate a new one under **Account → API**. |
